## Features
Shows a list of raid members that are missing common raid buffs.

Forked from https://www.curseforge.com/wow/addons/missing-raid-buffs due to the original author abandoning the project at the request of several users playing Classic Era patch 1.15.9.

## Release Schedule
New builds are created On Demand and will generally only include updated TOC versions unless significant code changes are required for compatibility.
